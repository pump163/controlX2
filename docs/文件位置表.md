> 生成日期：2026-11-04。用途：找文件。只收**我们自己写的 / 自己维护的** md；
> 上游自带的 `AGENTS.md`、`README.md`、`NIGHTSCOUT.plan.md`、`.claude/plans/*` 以及工具生成的 `i18n/reports`、`i18n/.cache` 不收录。

## 怎么读

| 列 | 含义 |
|---|---|
| 文件名 | 文件名（不含路径） |
| 原位置 | 建立时 / 搬家前的路径（相对所在树根） |
| 现位置 | 搬家后的路径；**空着 = 没动过，仍在原位置** |
| 说明 | 一句话内容 + 状态 |

## 归档规则（2026-11-04 定稿）

1. 已完成的、意义不大的 → 各自树的 `docs/old/`。
2. 未完成 / 部分完成的 → 统一到 `controlX2-i18n_pumppan/docs/`，按 `feature/`、`bug/` 分类。
3. 跨树搬来的重名文件 → 加来源后缀：`_main` = 来自 `controlX2-i18n`。
4. 已并入 WORKLOG 的账本类文档 → 原文件进 `old/`，只留一处维护。
