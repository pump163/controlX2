# UI 组件目录规范

> 目的：在汉化过程中同步规范化组件放置，降低查找成本和 import 错误。
> 视觉美化（换色/换样式）是远期任务；**目录规范化现在就做**。

## mobile 端

路径：`mobile/src/main/java/com/jwoglom/controlx2/presentation/components/`

| 子目录 | 职责 | 组件示例 |
|--------|------|----------|
| `controls/` | 交互控件（行、开关、对话框、设置组） | ToggleRow, NavigationRow, ActionRow, StatusRow, ActionConfirmDialog, SettingsGroup |
| `input/` | 输入控件 | DecimalOutlinedText, IntegerOutlinedText, PairingCodeInput, DexcomG6SensorCode, DexcomG6TransmitterCode |
| `feedback/` | 反馈/状态展示 | LoadSpinner, ServiceDisabledMessage, NotificationItem, HistoryLogSyncProgressBar, LastConnectionUpdatedTimestamp |
| `pump/` | 泵状态可视化 | HorizBatteryIcon, HorizCartridgeIcon, PumpStatusBar, PumpSetupStageDescription, PumpSetupStageProgress |
| `layout/` | 布局/结构容器 | HeaderLine, Line, DialogScreen, VersionInfo |
| `charts/` | 图表 | DashboardCgmChart, VicoCgmChart |

**判定规则：**
- 被 ≥2 个页面引用 → 归入 `components/` 对应子目录
- 仅被单个 section 引用 → 留在 `screens/sections/components/` 对应该 section 子目录
- 配对流程专用组件 → `pump/`

## wear 端

路径：`wear/src/main/java/com/jwoglom/controlx2/presentation/components/`

| 子目录 | 职责 | 组件示例 |
|--------|------|----------|
| `chips/` | 芯片组件 | FirstRowChip, LineInfoChip, MiniChip, LandingBolusChip, BolusUnitsChip |
| `controls/` | 交互控件 | DecimalNumberPicker, SingleNumberPicker, RemoteTextInput |
| `text/` | 文本组件 | TopText, BottomText, CustomTimeText, LineTextDescription, LastConnectionText, CurrentCGMText |
| `input/` | 输入控件 | （预留） |

## 迁移规则

1. 移动文件后同步更新 `package` 声明
2. 所有引用处的 `import` 路径同步更新
3. 每批移动后必须编译通过
4. section 私有组件（bolus/、cards/、cartridge/、dialogs/）不移动
