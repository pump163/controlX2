# 星期位掩码对照表

> 已停用（2026-11-04 归档）：原为睡眠计划星期选择器整理，该选择器已不再使用；内容仅作历史参考。

| 星期 | 位位置 | 十进制值 | 二进制 |
|------|--------|----------|--------|
| 周一 | 0 | 1 | `0000001` |
| 周二 | 1 | 2 | `0000010` |
| 周三 | 2 | 4 | `0000100` |
| 周四 | 3 | 8 | `0001000` |
| 周五 | 4 | 16 | `0010000` |
| 周六 | 5 | 32 | `0100000` |
| 周日 | 6 | 64 | `1000000` |
| **全选（七天）** | — | **127** | `1111111` |

## 常用组合速查

| 组合 | 值 | 计算 |
|------|-----|------|
| 工作日（周一~周五） | 31 | 1+2+4+8+16 |
| 周末（周六+周日） | 96 | 32+64 |
| 周一、三、五 | 21 | 1+4+16 |
| 每天（全选） | 127 | 1+2+4+8+16+32+64 |

## 程序里常用的判断方式

```kotlin
// 判断某天是否被选中（以周一为例）
val isMondaySelected = (bitmask and 1) != 0

// 判断某天是否被选中（通用）
fun isDaySelected(bitmask: Int, dayValue: Int): Boolean {
    return (bitmask and dayValue) != 0
}

// 把位掩码转成选中的星期列表
fun bitmaskToDays(bitmask: Int): List<String> {
    val dayMap = listOf(
        1 to "周一", 2 to "周二", 4 to "周三",
        8 to "周四", 16 to "周五", 32 to "周六", 64 to "周日"
    )
    return dayMap.filter { (value, _) -> (bitmask and value) != 0 }
                 .map { (_, name) -> name }
}
```
