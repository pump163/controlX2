# pumpx2 命令 X2 泵固件不支持记录

## 背景
controlX2 App 代码没有限制设备（`@MessageProps` 的 `supportedDevices` 默认 ALL），但 Tandem X2 泵固件不执行某些命令。点了之后蓝牙有连接，但泵本身没反应。

## 已确认 X2 泵固件不支持的命令

### 1. 停止/启动胰岛素
- **代码位置**：`Actions.kt` 停止胰岛素按钮
- **请求类**：`StopDeliveryRequest` / `ResumeDeliveryRequest`
- **现象**：点了之后蓝牙有连接，但泵没反应
- **结论**：X2 泵固件不支持远程停止/启动命令

### 2. 同步胰岛素泵时间
- **代码位置**：`Settings.kt` 同步胰岛素泵时间
- **请求类**：`ChangeTimeDateRequest`
- **现象**：点了之后蓝牙有连接，但泵没反应
- **结论**：X2 泵固件不支持远程改时间

### 3. 查找我的胰岛素泵
- **代码位置**：`Settings.kt` 查找我的胰岛素泵
- **请求类**：`PlaySoundRequest`
- **现象**：点了之后蓝牙有连接，但泵没反应
- **结论**：X2 泵固件不支持远程播放声音

## 说明
- 这些命令在 Mobi 泵上应该是支持的
- X2 泵固件限制，不是 App 代码问题
- 代码不需要改（保留按钮，用户点了没反应就知道不支持）
